rsi package · live runs with Claude Haiku

Watching the loop improve an LLM agent, one iteration at a time

Each run below started from an untouched seed and ran through the package's public API. Claude Haiku played both roles: the frozen model the harness calls, and the proposer that rewrites the harness. Every point on a chart is one candidate the model proposed, scored by a locked exact-match grader. The orange and green lines are sealed held-out and out-of-distribution tasks. The loop never saw them; a write-only monitor scored each new incumbent on them.

Reproduce: python experiments/demo/live_demo.py metaharness|rrsi|autoresearch, then python experiments/demo/plot_demo.py && python experiments/demo/build_page.py. Full per-step traces (prompts, diffs, gate arithmetic) are in demo/runs/<run>/TRACE.md. Small task sets (12 practice, 8 held-out, 8 OOD) make single runs noisy; treat each chart as one real trajectory, not a benchmark.
