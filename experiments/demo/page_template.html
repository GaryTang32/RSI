rsi package · live runs with Claude Haiku

Watching the loop improve an LLM agent, one iteration at a time

Each run below started from an untouched seed and ran through the package's public API (some were cut short by the account's usage cap, a container restart or a crash and resumed from their LLM cache). In the AgentQA runs Claude Haiku played both roles: the frozen model the harness calls, and the proposer that rewrites the harness; every point on their charts is one candidate the model proposed, scored by a locked exact-match grader. In autoresearch Haiku edits a training script, and every point is one 8-second training run scored by validation bits per byte. On the AgentQA charts the orange and green lines are sealed held-out and out-of-distribution tasks: the loop never saw any of those tasks or their scores, and a write-only monitor scored each new incumbent on them. The proposer's domain description does name the OOD kinds (e.g. "business-day scheduling, chained text transformations"), so OOD measures transfer to unseen tasks of announced kinds. Where a run was re-scored, the result line above its chart is that re-score, with fresh trials; other result lines say what they show. The AgentQA charts show in-loop scores and monitor readings, one trial per task; RRSI's rounds 0, 1, 2 are iterations 1, 2, 3 on its charts.

Check the committed results at $0 (offline; a cache miss is an error): python experiments/demo/live_demo.py metaharness [--suite hard] --replay-check, rescore.py, leak_ablation.py, monitor_check.py, calibrate_hard.py and spend.py (all in experiments/demo/), then rebuild with plot_demo.py && build_page.py. New results: live_demo.py metaharness|rrsi|autoresearch [--suite hard], rescore.py --record <run> or --seed-offset N for new trials, spend.py --force only on the machine that made the calls. Full per-step traces (prompts, diffs, gate arithmetic) are in demo/runs/<run>/TRACE.md. Small task sets (standard: 12 practice, 8 held-out, 8 OOD; hard: 8, 6, 6) make single runs noisy; treat each chart as one real trajectory, not a benchmark.
